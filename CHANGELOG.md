# Changelog

All notable changes to `filament-utilities` will be documented in this file.

## 0.1.0 - 2026-06-06

### Added

- `syriable:make-resource` command extending Filament's resource generator with translatable base classes.
- `plugin:resource` command for scaffolding Filament panel plugins in modular applications.
- Custom resource and page file generators integrated with `syriable/filament-translator`.
- Module-aware Eloquent model discovery for interactive resource generation.
- README, security policy, and contributing documentation.
